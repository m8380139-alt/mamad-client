# Mamad Client

کلاینت ممدکرفت برای ماینکرفت ۱.۸.۹ (Forge).

- قدم اول: نمایش کیپ بازیکن‌ها از سایت [MamadCraft](https://m8380139-alt.github.io/mamadcraft/)
- ساخته‌شده روی [Forge1.8.9Template](https://github.com/nea89o/Forge1.8.9Template) (Unlicense)

## بیلد
`./gradlew build` ← فایل jar تو `build/libs/` ساخته می‌شه. GitHub Actions هم خودکار بیلد می‌گیره (Artifacts).
